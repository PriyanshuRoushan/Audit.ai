## Hardest Bug

The hardest challenge was designing recommendation logic that felt realistic and useful instead of generic.

Initially, AI-generated recommendations were inconsistent. I redesigned the system into a deterministic rule-based engine using:
- team-size rules
- duplicate tool detection
- plan downgrade recommendations

This improved reliability and trust.

## Decision I Reversed

Initially, I planned to make the audit engine mostly AI-generated.

Later, I reversed this decision because financial recommendations require explainable and consistent logic.

AI is now mainly used for:
- summaries
- explanations
- recommendation descriptions
