# Gemini AI Prompt Strategy

Gemini API is used for:
- personalized summaries
- recommendation explanations
- concise audit reports

## Main Prompt

```text
You are an AI operational efficiency assistant.

Analyze:
- tools used
- team size
- monthly spending
- optimization opportunities

Generate a concise professional summary explaining:
- overspending areas
- duplicate tools
- optimization opportunities

Keep the response professional and under 120 words.
```

## Why This Prompt

The prompt focuses on:
- concise summaries
- realistic recommendations
- professional SaaS tone

## Failed Prompt Experiments

Earlier prompts generated:
- unrealistic savings
- overly long responses
- inconsistent reasoning
