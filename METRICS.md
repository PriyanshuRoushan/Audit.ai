# METRICS.md

# North Star Metric

## Completed AI Audits

The primary success metric is the number of completed audits.

This indicates:
- user engagement
- operational interest
- lead generation potential

## Supporting Metrics

### Audit Completion Rate
Measures onboarding and UX quality.

### Shareable Report Usage
Measures virality and collaboration value.

### Consultation Requests
Measures monetization potential.

## Initial Analytics

Track:
- dashboard visits
- audit starts
- audit completions
- report shares
- email submissions

## Pivot Trigger

If users complete audits but do not:
- share reports
- request consultations
- return to the platform

then recommendation quality likely needs improvement.
